# 六韬

- 作者：姜子牙
- 朝代：先秦
- 分类：子部 / 兵家类
- 章节数：60

## 简介

《六韬》又称《太公六韬》、《太公兵法》，是中国古代的一部著名的道家兵书。中国汉族古典军事文化遗产的重要组成部分，其内容博大精深，思想精邃富赡，逻辑缜密严谨，是古代汉族军事思想精华的集中体现。全书有六卷，共六十篇。《六韬》的内容十分广泛，对有关战争和各方面问题，几乎都涉及到了。其中最精彩的部分是它的战
