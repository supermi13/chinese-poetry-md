# 鬼谷子

- 作者：佚名
- 朝代：先秦
- 分类：子部 / 杂家类
- 章节数：21

## 简介

《鬼谷子》，又名《捭阖策》。据传是由鬼谷先生后学者根据先生言论整理而成。该书侧重于权谋策略及言谈辩论技巧。《鬼谷子》共有十四篇，其中第十三、十四篇已失传。
