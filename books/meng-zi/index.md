# 孟子

- 作者：佚名
- 朝代：先秦
- 分类：经部 / 礼类
- 章节数：261

## 简介

《孟子》四书之一。战国中期孟子及其弟子万章、公孙丑等著。为孟子、孟子弟子、再传弟子的记录。最早见于赵岐《孟子题辞》：“此书，孟子之所作也，故总谓之《孟子》”。《汉书·艺文志》著录《孟子》十一篇，现存七篇十四卷。总字数三万五千余字，286章。相传另有《孟子外书》四篇，已佚（今本《孟子外书》系明姚士粦伪
