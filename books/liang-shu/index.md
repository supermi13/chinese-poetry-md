# 梁书

- 作者：姚思廉
- 朝代：唐
- 分类：史部 / 正史类
- 章节数：56

## 简介

《梁书》包含本纪六卷、列传五十卷，无表、无志。它主要记述了南朝萧齐末年的政治和萧梁皇朝（502—557年）五十余年的史事。其中有二十六卷的后论署为“陈吏部尚书姚察曰”，说明这些卷是出于姚察之手，这几乎占了《梁书》的半数。姚思廉撰《梁书》，除了继承他父亲的遗稿以外，还参考、吸取了梁、陈、隋历朝史家编撰
