# 文心雕龙

- 作者：刘勰
- 朝代：南北朝
- 分类：集部 / 诗文评类
- 章节数：50

## 简介

《文心雕龙》是中国南朝文学理论家刘勰创作的一部文学理论著作，成书于公元501～502年（南朝齐和帝中兴元、二年）间。全书共10卷，50篇（原分上、下部，各25篇），以孔子美学思想为基础，兼采道家，全面总结了齐梁时代以前的美学成果，细致地探索和论述了语言文学的审美本质及其创造、鉴赏的美学规律。
