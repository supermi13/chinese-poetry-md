# 容斋随笔

- 作者：洪迈
- 朝代：宋
- 分类：子部 / 杂家类
- 章节数：329

## 简介

《容斋随笔》共《五笔》，74卷，1220则。其中，《容斋随笔》16卷，329则；《容斋续笔》16卷，249则；《容斋三笔》16卷，248则；《容斋四笔》16卷，259则；《容斋五笔》10卷，135则。据作者宋朝洪迈自述，《容斋随笔》写作时间逾经近四十年。是其多年博览群书、经世致用的智慧和汗水的结晶。
