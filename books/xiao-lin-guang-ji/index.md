# 笑林广记

- 作者：游戏主人
- 朝代：清
- 分类：子部 / 杂家类
- 章节数：12

## 简介

中国有笑话书的历史由来已久，但集大成者可说非《笑林广记》莫属。此书作者「游戏主人」编成，游戏主人并不是指一个人而是清代的一批文人一起编写而成的《笑林广记》可算是严格意义上的笑话集，语言风趣，文字简练隽秀，表现手法也十分成熟。
