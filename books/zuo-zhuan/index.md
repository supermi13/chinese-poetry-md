# 左传

- 作者：左丘明
- 朝代：先秦
- 分类：经部 / 春秋类
- 章节数：255

## 简介

《左传》原名为《左氏春秋》，汉代改称《春秋左氏传》，简称《左传》。旧时相传是春秋末年左丘明为解释孔子的《春秋》而作。《左传》实质上是一部独立撰写的史书。它起自鲁隐公元年（前722年），迄于鲁悼公十四年（前453年），以《春秋》为本，通过记述春秋时期的具体史实来说明《春秋》的纲目，是儒家重要经典之一。
