# 镜花缘

- 作者：李汝珍
- 朝代：清
- 分类：子部 / 小说家类
- 章节数：100

## 简介

《镜花缘》是清代继《红楼梦》之后出现的一部优秀长篇小说。书的内容可分前后两个部分，前半部叙述武则天当政时代，秀才唐敖因与反对武氏失败的徐敬业、骆宾王有牵连，仕途蹇滞，随其妻弟林之洋飘洋出海，到十多个国家，获丰富的阅历，终有所悟，遁入仙山小蓬莱。关于各国风俗民情的描写，是该书的精粹所在。后半部写唐敖之
