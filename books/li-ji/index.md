# 礼记

- 作者：佚名
- 朝代：先秦
- 分类：经部 / 礼类
- 章节数：49

## 简介

《礼记》，是中国古代一部重要的典章制度书籍，儒家经典著作之一。该书编定是西汉戴圣对秦汉以前各种礼仪著作加以辑录，编纂而成，共49篇。《礼记》大约是战国末年或秦汉之际儒家学者托名孔子答问的著作。
