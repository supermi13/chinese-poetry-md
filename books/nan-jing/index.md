# 难经

- 作者：扁鹊
- 朝代：汉
- 分类：子部 / 医家类
- 章节数：81

## 简介

《难经》是战国时期 出版的图书，作者是扁鹊 ，原名《黄帝八十一难经》，古代中医学著作之一，传说为战国时期秦越人（扁鹊）所作。本书以问答解释疑难的形式编撰而成，共讨论了81个问题，故又称《八十一难》，全书所述以基础理论为主，还分析了一些病证。其中一至二十二难为脉学，二十三至二十九难为经络，三十至四十七
