# 南齐书

- 作者：萧子显
- 朝代：南北朝
- 分类：史部 / 正史类
- 章节数：59

## 简介

《南齐书》，南朝梁萧子显撰，记述南朝萧齐王朝自齐高帝建元元年（479年）至齐和帝中兴二年（502年），共二十三年史事，是现存关于南齐最早的纪传体断代史。
